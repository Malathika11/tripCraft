# TripCraft

A full-stack travel planning application.

## Technologies

- Angular
- Node.js
- Express.js
- MySQL

## Features

- Flight Sector Search
- Budget Planning
- Travel Date Selection
- Dynamic Forms

## Run Frontend

```bash
npm install
ng serve
```

## Run Backend

```bash
cd backend
npm install
node server.js
```

## Database

Import:

```
database/tourdb.sql
```

into MySQL Workbench.
