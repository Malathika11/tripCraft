# TripCraft

TripCraft is a full-stack travel planning application built using:

- Angular
- Node.js
- Express.js
- MySQL

## Features

- Flight Sector Search
- Budget Planner
- Travel Date Selection
- Dynamic Forms

## Installation

### Frontend

```bash
npm install
ng serve
```

### Backend

```bash
cd backend
npm install
node server.js
```

### Database

Import:

```
database/tourdb.sql
```

into MySQL Workbench.
